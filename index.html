Como usar este guia

Todos os capítulos usam o mesmo projeto: uma aplicação em Python que regista o inventário de uma sala e os problemas de cada computador. No fim, a documentação completa dessa aplicação fica pronta.

Objetivos do módulo

  • Especificar os requisitos de uma aplicação de gestão.
  • Elaborar diagramas de casos de uso.
  • Documentar o código e a arquitetura da aplicação.
  • Produzir relatórios com dados da aplicação.

Como cada capítulo está organizado

  • Explicação: o conceito, para que serve e como se faz.
  • Exemplo: um exemplo completo no inventário da sala.
  • Dicas e avisos: erros frequentes e boas práticas.
  • Exercícios: com nível (básico, intermédio, avançado) e o que entregar.

Elementos de um diagrama

ElementoRepresentaçãoSignificado
AtorBoneco com nomeQuem interage com o sistema. É um papel, não uma pessoa concreta.
Caso de usoElipse com um verboUm objetivo do ator, por exemplo «Registar problema».
FronteiraRetânguloSepara o que está dentro do sistema do que está fora.
AssociaçãoLinha contínuaLiga um ator aos casos de uso em que participa.
«include»Seta tracejadaO caso base precisa sempre de outro.
«extend»Seta tracejadaComportamento opcional, só em certas condições.

Como construir o diagrama

  1. Identificar os atores: quem usa e quem recebe resultados.
  2. Listar os objetivos de cada ator: «O ator quer…».
  3. Nomear os casos de uso com verbo no infinitivo e objeto: «Registar computador», não «Fazer INSERT».
  4. Desenhar a fronteira, com os casos de uso dentro e os atores fora.
  5. Ligar atores e casos de uso.
  6. Procurar include (passos repetidos) e extend (comportamento ocasional).
  7. Validar: cada RF aparece em pelo menos um caso de uso.

Cuidado

Não desenhe o fluxo de passos no diagrama: isso é um fluxograma. Os passos vão na ficha do caso de uso.

O que é o Markdown

Markdown é uma forma de escrever texto formatado usando só caracteres normais. Os ficheiros têm a extensão .md. Qualquer pessoa os lê tal como estão, e o GitHub, o VS Code e as wikis convertem-nos em página formatada. É o formato mais usado na documentação de projetos de software. Vantagens: não precisa de programa especial para escrever, fica guardado em texto simples no Git e converte-se em HTML ou PDF.

Fazer documentação em Markdown, passo a passo

  1. Criar o ficheiro README.md na pasta do projeto.
  2. Planear as secções (##): o que é, requisitos, instalação, como usar, estrutura, resolução de problemas.
  3. Escrever, com uma linha em branco entre parágrafos, listas, tabelas e blocos de código.
  4. Pré-visualizar no VS Code com Ctrl+Shift+V (Mac: Cmd+Shift+V).
  5. Rever: blocos fechados, tabelas alinhadas, ligações a funcionar. Releia como um colega que não conhece o projeto.
  6. Converter, se preciso: pandoc README.md -o README.html, ou imprimir a pré-visualização para PDF.
  7. Guardar versões: git add README.md e git commit -m "Atualiza README".

Erros comuns

Faltar a linha em branco antes de lista ou tabela; não fechar o bloco de código; tabela sem a linha |---|---|; escrever #Título sem espaço.

git clone https://github.com/<utilizador>/inventario-sala.git
cd inventario-sala
python main.py

## Como usar
Ao executar `python main.py` aparece o menu:
1. Listar computadores  2. Registar computador  3. Registar problema
4. Resolver problema  5. Relatório da sala  0. Sair

**Exemplo – registar uma avaria:**
1. Escolha a opção `3`.
2. Escreva a etiqueta do computador, por exemplo `PC-12-02`.
3. Escreva a descrição e a gravidade (`baixa`, `media` ou `alta`).

Passo 1 · Ligar à base de dados

import sqlite3
conn = sqlite3.connect("inventario.db")  # cria o ficheiro se não existir
conn.row_factory = sqlite3.Row            # colunas pelo nome
conn.execute("PRAGMA foreign_keys = ON")  # ativa as chaves estrangeiras

Use ":memory:" para uma base temporária, ideal para testes. A última linha é necessária em cada ligação.

Passo 3 · Inserir dados, sempre com parâmetros

conn.execute(
 "INSERT INTO computador (sala_id, etiqueta, ram_gb) VALUES (?, ?, ?)",
 (1, "PC-12-01", 16))
conn.commit()  # sem commit() as alterações perdem-se

Nunca junte texto do utilizador ao SQL. Com ' OR '1'='1, a versão errada devolve 3 linhas e a certa devolve 0. Repare na vírgula em (etiqueta,): faz do valor um tuplo.

Passo 4 · Transação

with conn:
 conn.execute("INSERT INTO problema (computador_id, descricao) VALUES (?, ?)", (1, "Ecrã não liga"))
 conn.execute("UPDATE computador SET estado = 'avariado' WHERE id = ?", (1,))

Ou acontecem as duas, ou nenhuma. with conn não fecha a ligação.

Passos 5 e 6 · Consultar, atualizar e apagar

for pc in conn.execute("SELECT etiqueta, ram_gb FROM computador ORDER BY etiqueta"):
    print(pc["etiqueta"], pc["ram_gb"])
pc = conn.execute("SELECT * FROM computador WHERE etiqueta = ?", ("PC-12-01",)).fetchone()
if pc is None:
    print("Esse computador não existe")
cur = conn.execute("UPDATE computador SET estado = ? WHERE etiqueta = ?", ("em_reparacao", "PC-12-02"))
conn.commit()
print(cur.rowcount, "registo(s) alterado(s)")  # 0: a etiqueta não existe

fetchall() devolve uma lista; fetchone() devolve a primeira linha ou None. Um UPDATE ou DELETE sem WHERE afeta todas as linhas.

Computadores por sala, incluindo as vazias

SELECT s.nome, COUNT(c.id) AS total
FROM sala s LEFT JOIN computador c ON c.sala_id = s.id
GROUP BY s.id;

Com LEFT JOIN, ponha a condição no ON, não no WHERE, para manter linhas sem correspondência. Exemplo de resultado: Sala 12 → 3; Sala 14 → 0.

Problemas por resolver em cada computador

Os computadores sem problemas também aparecem, porque a condição está no ON.

SELECT c.etiqueta, COUNT(p.id) AS abertos
FROM computador c
LEFT JOIN problema p ON p.computador_id = c.id AND p.resolvido = 0
GROUP BY c.id
ORDER BY abertos DESC, c.etiqueta;

Cuidado

Com WHERE p.resolvido = 0 num LEFT JOIN, os computadores sem problemas desaparecem do resultado.

Tempo médio de resolução, em dias

julianday converte uma data em número de dias, o que permite subtraí-las.

SELECT ROUND(AVG(julianday(data_resolucao) - julianday(data_registo)), 1) AS dias
FROM problema
WHERE resolvido = 1;

Salas com avariados

SELECT s.nome, COUNT(*) AS avariados
FROM computador c JOIN sala s ON s.id = c.sala_id
WHERE c.estado = 'avariado'
GROUP BY s.nome
HAVING COUNT(*) > 0;

relatorio.py

Separe a obtenção dos dados (SQL) da apresentação (Markdown, CSV). Assim gera o mesmo conteúdo em vários formatos.

"""Relatórios do Inventário da Sala: Markdown e CSV."""
import csv
from datetime import date
import db

def contar_por_estado(conn):
    """Quantos computadores há em cada estado?"""
    return conn.execute(
        """SELECT estado, COUNT(*) AS total FROM computador
           GROUP BY estado ORDER BY total DESC""").fetchall()

def problemas_por_computador(conn):
    """Computadores com problemas por resolver (LEFT JOIN + GROUP BY)."""
    return conn.execute(
        """SELECT c.etiqueta, COUNT(p.id) AS abertos
           FROM computador c
           LEFT JOIN problema p
                  ON p.computador_id = c.id AND p.resolvido = 0
           GROUP BY c.id
           ORDER BY abertos DESC, c.etiqueta""").fetchall()

def relatorio_markdown(conn, sala_nome):
    """Gera um relatório em Markdown e devolve-o como texto."""
    linhas = [f"# Relatório da {sala_nome}",
              f"_Gerado em {date.today().isoformat()}_", "",
              "## Computadores", "",
              "| Etiqueta | Marca | Modelo | RAM (GB) | Estado |",
              "|----------|-------|--------|---------:|--------|"]
    for pc in db.listar_computadores(conn, sala_nome):
        linhas.append(f"| {pc['etiqueta']} | {pc['marca']} | {pc['modelo']} "
                      f"| {pc['ram_gb']} | {pc['estado']} |")
    linhas += ["", "## Resumo por estado", ""]
    for r in contar_por_estado(conn):
        linhas.append(f"- **{r['estado']}**: {r['total']}")
    linhas += ["", "## Problemas por resolver", ""]
    abertos = db.listar_problemas_abertos(conn)
    if not abertos:
        linhas.append("Nenhum problema por resolver.")
    for p in abertos:
        linhas.append(f"- `{p['etiqueta']}` ({p['gravidade']}): {p['descricao']}")
    return "\n".join(linhas) + "\n"

def exportar_csv(conn, caminho, sala_nome=None):
    """Exporta a lista de computadores para um ficheiro CSV."""
    linhas = db.listar_computadores(conn, sala_nome)
    with open(caminho, "w", newline="", encoding="utf-8") as f:
        w = csv.writer(f, delimiter=";")
        w.writerow(["etiqueta", "marca", "modelo", "so", "ram_gb", "estado", "sala"])
        for r in linhas:
            w.writerow(list(r))
    return len(linhas)

relatorio_markdown devolve texto em vez de imprimir: pode gravá-lo, mostrá-lo ou testá-lo. Para gravar: open("relatorios/sala12.md", "w", encoding="utf-8") e ficheiro.write(...).

"""Acesso à base de dados do Inventário da Sala (SQLite).

Este módulo concentra TODO o acesso à base de dados: o resto da
aplicação limita-se a chamar estas funções.
"""
import sqlite3

FICHEIRO_BD = "inventario.db"
ESQUEMA = """
CREATE TABLE IF NOT EXISTS sala (
 id INTEGER PRIMARY KEY AUTOINCREMENT,
 nome TEXT NOT NULL UNIQUE,
 edificio TEXT);
CREATE TABLE IF NOT EXISTS computador (
 id INTEGER PRIMARY KEY AUTOINCREMENT,
 sala_id INTEGER NOT NULL REFERENCES sala(id),
 etiqueta TEXT NOT NULL UNIQUE,
 marca TEXT, modelo TEXT, sistema_operativo TEXT,
 ram_gb INTEGER CHECK (ram_gb > 0),
 estado TEXT NOT NULL DEFAULT 'operacional'
  CHECK (estado IN ('operacional','avariado','em_reparacao','abatido')));
CREATE TABLE IF NOT EXISTS problema (
 id INTEGER PRIMARY KEY AUTOINCREMENT,
 computador_id INTEGER NOT NULL REFERENCES computador(id),
 descricao TEXT NOT NULL,
 gravidade TEXT NOT NULL DEFAULT 'media'
  CHECK (gravidade IN ('baixa','media','alta')),
 data_registo TEXT NOT NULL DEFAULT (date('now')),
 resolvido INTEGER NOT NULL DEFAULT 0,
 data_resolucao TEXT);
"""

def ligar(ficheiro=FICHEIRO_BD):
    """Abre a ligação à base de dados e ativa as chaves estrangeiras.

    Args:
        ficheiro: caminho do ficheiro .db (use ":memory:" nos testes).
    Returns:
        sqlite3.Connection com row_factory = sqlite3.Row, para podermos
        aceder às colunas pelo nome (linha["etiqueta"]).
    """
    conn = sqlite3.connect(ficheiro)
    conn.row_factory = sqlite3.Row
    conn.execute("PRAGMA foreign_keys = ON")
    return conn

def criar_tabelas(conn):
    """Cria as tabelas se ainda não existirem."""
    with conn:
        conn.executescript(ESQUEMA)

def adicionar_sala(conn, nome, edificio=None):
    """Insere uma sala e devolve o id gerado."""
    with conn:
        cur = conn.execute("INSERT INTO sala (nome, edificio) VALUES (?, ?)", (nome, edificio))
    return cur.lastrowid

def adicionar_computador(conn, sala_id, etiqueta, marca, modelo, sistema_operativo, ram_gb):
    """Insere um computador (estado inicial: operacional)."""
    with conn:
        cur = conn.execute(
            """INSERT INTO computador (sala_id, etiqueta, marca, modelo, sistema_operativo, ram_gb)
               VALUES (?, ?, ?, ?, ?, ?)""",
            (sala_id, etiqueta, marca, modelo, sistema_operativo, ram_gb))
    return cur.lastrowid

def registar_problema(conn, etiqueta, descricao, gravidade="media"):
    """Regista um problema. Se a gravidade for 'alta', o computador passa a 'avariado'.
    Raises: ValueError se não existir computador com essa etiqueta."""
    pc = conn.execute("SELECT id FROM computador WHERE etiqueta = ?", (etiqueta,)).fetchone()
    if pc is None:
        raise ValueError(f"Computador '{etiqueta}' não existe")
    with conn:
        cur = conn.execute(
            "INSERT INTO problema (computador_id, descricao, gravidade) VALUES (?, ?, ?)",
            (pc["id"], descricao, gravidade))
        if gravidade == "alta":
            conn.execute("UPDATE computador SET estado = 'avariado' WHERE id = ?", (pc["id"],))
    return cur.lastrowid

def resolver_problema(conn, problema_id):
    """Marca um problema como resolvido, com a data de hoje."""
    with conn:
        conn.execute("UPDATE problema SET resolvido = 1, data_resolucao = date('now') WHERE id = ?",
                     (problema_id,))

def listar_computadores(conn, sala_nome=None):
    """Devolve os computadores (todos, ou só de uma sala)."""
    sql = """SELECT c.etiqueta, c.marca, c.modelo, c.sistema_operativo,
                    c.ram_gb, c.estado, s.nome AS sala
             FROM computador c JOIN sala s ON s.id = c.sala_id"""
    params = ()
    if sala_nome:
        sql += " WHERE s.nome = ?"
        params = (sala_nome,)
    return conn.execute(sql + " ORDER BY c.etiqueta", params).fetchall()

def listar_problemas_abertos(conn):
    """Devolve os problemas por resolver, os mais graves primeiro."""
    return conn.execute(
        """SELECT p.id, c.etiqueta, p.descricao, p.gravidade, p.data_registo
           FROM problema p JOIN computador c ON c.id = p.computador_id
           WHERE p.resolvido = 0
           ORDER BY CASE p.gravidade WHEN 'alta' THEN 1 WHEN 'media' THEN 2 ELSE 3 END,
                    p.data_registo""").fetchall()

"""Menu em consola do Inventário da Sala."""
import sqlite3
import db
import relatorio

MENU = """
=== INVENTÁRIO DA SALA ===
1. Listar computadores
2. Registar computador
3. Registar problema
4. Resolver problema
5. Relatório da sala
0. Sair"""

def listar(conn):
    for pc in db.listar_computadores(conn):
        print(f'{pc["etiqueta"]:9} {pc["marca"]:6} {pc["ram_gb"]:>2} GB {pc["estado"]}')

def novo_computador(conn):
    sala = input("Nome da sala: ")
    linha = conn.execute("SELECT id FROM sala WHERE nome = ?", (sala,)).fetchone()
    sala_id = linha["id"] if linha else db.adicionar_sala(conn, sala)
    try:
        db.adicionar_computador(conn, sala_id, input("Etiqueta: "), input("Marca: "),
            input("Modelo: "), input("Sistema operativo: "), int(input("RAM (GB): ")))
        print("Computador registado.")
    except (sqlite3.IntegrityError, ValueError) as erro:
        print("Não foi possível registar:", erro)

def novo_problema(conn):
    try:
        db.registar_problema(conn, input("Etiqueta: "), input("Descrição: "),
                             input("Gravidade (baixa/media/alta): "))
        print("Problema registado.")
    except (sqlite3.IntegrityError, ValueError) as erro:
        print("Não foi possível registar:", erro)

def resolver(conn):
    for p in db.listar_problemas_abertos(conn):
        print(f'#{p["id"]} {p["etiqueta"]} [{p["gravidade"]}] {p["descricao"]}')
    db.resolver_problema(conn, int(input("Número do problema a resolver: ")))
    print("Problema resolvido.")

def main(ficheiro=db.FICHEIRO_BD):
    conn = db.ligar(ficheiro)
    db.criar_tabelas(conn)
    acoes = {"1": listar, "2": novo_computador, "3": novo_problema, "4": resolver,
             "5": lambda c: print(relatorio.relatorio_markdown(c, input("Sala: ")))}
    while True:
        print(MENU)
        opcao = input("Opção: ")
        if opcao == "0":
            break
        acoes.get(opcao, lambda c: print("Opção inválida."))(conn)
    conn.close()

if __name__ == "__main__":
    main()

SELECT s.nome, COUNT(c.id) AS total

GROUP BY s.id;

SELECT etiqueta, ram_gb FROM computador WHERE ram_gb < 8 ORDER BY ram_gb;

-- (c) Problemas de gravidade alta por resolver
SELECT c.etiqueta, p.descricao
FROM problema p JOIN computador c ON c.id = p.computador_id
WHERE p.resolvido = 0 AND p.gravidade = 'alta';

-- (d) Computadores sem nenhum problema registado
SELECT c.etiqueta FROM computador c
WHERE NOT EXISTS (SELECT 1 FROM problema p WHERE p.computador_id = c.id);

-- (e) Tempo médio de resolução, em dias
SELECT ROUND(AVG(julianday(data_resolucao) - julianday(data_registo)), 1) AS dias
FROM problema WHERE resolvido = 1;

SELECT s.nome, COUNT(*) AS avariados
FROM computador c JOIN sala s ON s.id = c.sala_id
WHERE c.estado = 'avariado'
GROUP BY s.nome;

"""Soluções propostas para alguns exercícios."""
import db

def historico_computador(conn, etiqueta):
    """Devolve todos os problemas (abertos e resolvidos) de um computador."""
    return conn.execute(
        """SELECT p.id, p.descricao, p.gravidade, p.data_registo,
                  p.resolvido, p.data_resolucao
           FROM problema p JOIN computador c ON c.id = p.computador_id
           WHERE c.etiqueta = ?
           ORDER BY p.data_registo, p.id""", (etiqueta,)).fetchall()

def relatorio_problemas_abertos(conn):
    """Devolve em Markdown a tabela de problemas por resolver."""
    linhas = ["# Problemas por resolver", "",
              "| Nº | Computador | Gravidade | Data | Descrição |",
              "|----|------------|-----------|------|-----------|"]
    for p in db.listar_problemas_abertos(conn):
        linhas.append(f"| {p['id']} | {p['etiqueta']} | {p['gravidade']} "
                      f"| {p['data_registo']} | {p['descricao']} |")
    return "\n".join(linhas) + "\n"

def percentagem_operacional(conn, sala_nome):
    """Percentagem de computadores operacionais numa sala (0 se não houver)."""
    total, ok = conn.execute(
        """SELECT COUNT(*), COALESCE(SUM(c.estado = 'operacional'), 0)
           FROM computador c JOIN sala s ON s.id = c.sala_id
           WHERE s.nome = ?""", (sala_nome,)).fetchone()
    return round(100 * ok / total, 1) if total else 0.0

def ficha_markdown(conn, etiqueta):
    """Gera a ficha em Markdown de um computador e do seu histórico."""
    pc = conn.execute(
        """SELECT c.*, s.nome AS sala, s.edificio
           FROM computador c JOIN sala s ON s.id = c.sala_id
           WHERE c.etiqueta = ?""", (etiqueta,)).fetchone()
    if pc is None:
        raise ValueError(f"Computador '{etiqueta}' não existe")
    linhas = [f"# Ficha do computador {pc['etiqueta']}", "",
              "| Campo | Valor |", "|-------|-------|",
              f"| Sala | {pc['sala']} ({pc['edificio']}) |",
              f"| Marca / modelo | {pc['marca']} {pc['modelo']} |",
              f"| Sistema operativo | {pc['sistema_operativo']} |",
              f"| RAM | {pc['ram_gb']} GB |",
              f"| Estado | {pc['estado']} |", "",
              "## Histórico de problemas", "",
              "| Nº | Data | Gravidade | Descrição | Resolvido |",
              "|----|------|-----------|-----------|-----------|"]
    for p in historico_computador(conn, etiqueta):
        linhas.append(f"| {p['id']} | {p['data_registo']} | {p['gravidade']} "
                      f"| {p['descricao']} | {'Sim' if p['resolvido'] else 'Não'} |")
    return "\n".join(linhas) + "\n"
